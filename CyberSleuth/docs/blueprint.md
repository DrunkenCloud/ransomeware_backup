# **App Name**: CyberSleuth

## Core Features:

- Interactive SQL Editor: Provide an interactive SQL editor with syntax highlighting and auto-completion.
- Guided Investigation Flow: Present scenario briefings and objectives in a clear, step-by-step format.
- Data Visualization: Display query results in a tabular format with sorting and filtering options.
- Contextual Help System: Incorporate hints and guidance for each step, gradually revealing more information as needed. This would be tool-assisted to reduce the need to re-run failed queries.
- Performance Scoreboard: Implement a scoring system that rewards correct queries and efficient investigation techniques.
- Reporting Module: Integrate a module where users can document their findings and generate a final incident report.

## Style Guidelines:

- Primary color: Dark blue (#1E3A8A), evoking trust, security, and authority.
- Background color: Very light gray (#F9FAFB) for a clean and unobtrusive backdrop.
- Accent color: Bright cyan (#06B6D4) to highlight key elements and interactive components.
- Body font: 'Inter' sans-serif font for clean and modern readability.
- Code font: 'Source Code Pro' monospaced font for displaying SQL queries and code snippets.
- Use consistent, outline-style icons to represent data types, actions, and investigation steps.
- Employ a grid-based layout to ensure consistent alignment and visual hierarchy across the application.
