# **App Name**: NetVis

## Core Features:

- Input Layer: 10x10 Pixel Grid Input: User-definable grid for simulating input images.
- Hidden Layer 1: Feature Detector Nodes: Create nodes with 10x10 patterns; activation is based on pixel match percentage.
- Hidden Layer 2: Feature Combination Nodes: Nodes combine activations from layer 1; activation is the average of selected nodes.
- Output Layer: Class Nodes: Output nodes show probability distribution based on selected nodes from layer 2, displayed as percentages.
- Real-time Propagation: Live Updates: All layers update live when user modifies input or nodes.

## Style Guidelines:

- Primary color: Saturated purple (#A050A0) to symbolize computation and vision in an engaging manner.
- Background color: Light gray (#F0F0F0), almost white, for a clean workspace with maximum visual contrast.
- Accent color: Turquoise (#40E0D0) to highlight interactive elements and activation signals distinctly.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern, neutral look and readability.
- Minimalist icons representing layers and nodes, clearly differentiating input, hidden, and output functions.
- Clearly sectioned layouts for each layer with intuitive node connection visualizations.
- Subtle transitions and animations to illustrate data flow and network activations.
