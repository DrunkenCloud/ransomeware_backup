# **App Name**: LineLearner

## Core Features:

- Data Point Input: Interactive 2D plane where users can add data points representing training cases.
- Line Adjustment: Adjustable linear regression line that users can manipulate to fit the training data.
- Simulation Setup: Simulation environment with 15 training data points and 5 testing data points.
- Performance Metrics: Real-time calculation and display of Variance, Bias, and Mean Squared Error (MSE) as the regression line is adjusted. The values update dynamically when dragging the line.
- Test Phase Trigger: A button to reveal the test data and finalize the simulation, providing a final score based on the user's adjusted line and the testing data.

## Style Guidelines:

- Primary color: Deep violet (#673AB7) for a sense of data-driven analysis and sophistication.
- Background color: Light violet (#F3E5F5) to keep a visual association with the primary color while minimizing distraction.
- Accent color: Electric indigo (#7C4DFF) for interactive elements and highlights, such as the adjustable regression line.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, objective presentation of data and instructions.
- Simple, geometric icons to represent data points, line adjustment tools, and performance metrics.
- Clean and well-spaced layout, separating the 2D plane, performance metrics display, and control buttons.
- Subtle transitions when adjusting the regression line and updating performance metrics.
