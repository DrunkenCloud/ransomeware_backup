# **App Name**: RansomAware

## Core Features:

- Lab Objectives Display: Display lab objectives and ransomware scenario summary in a static panel.
- Threat Actor Chat: Simulate a ransomware threat actor using a large language model tool to challenge student negotiation skills.
- Negotiation Chat Window: Provide a chat interface for students to interact with the simulated threat actor.
- Decryption Key Analysis: Validate decryption keys against a predefined correct key and provide feedback.
- Ethical Resources Display: Display links to articles and government guidelines on paying ransoms, and prompts for discussion.

## Style Guidelines:

- Primary color: A muted blue (#75A99C) to convey a sense of calm professionalism appropriate to business and legal scenarios.
- Background color: A light, desaturated blue (#E0F0ED) for a clean, non-distracting backdrop.
- Accent color: A soft yellow (#F2E2D0) to highlight key information and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a techy, modern feel; body font: 'Inter' (sans-serif) for readability.
- Static side panel for objectives, central chat window, and a separate utility for key analysis.
- Use simple, clear icons to represent different functions (e.g., chat, key validation, resources).
